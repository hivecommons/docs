- Fixed the `/docs/hive/operations/release-channels` page rendering as raw Markdown instead of a formatted page: `sanitizeHtmlForMdx`'s ambiguous-angle-bracket escape only matched bare `<word>` placeholders, so a placeholder with embedded text like `<branch tip>` reached the MDX compiler unescaped, was parsed as an unclosed JSX element, and failed compilation, triggering the raw-markdown fallback (hivecommons/docs#162).
- Fixed `/api/search` silently excluding every hive-project page (including release-channels) from results: it read page content from the shared `docs/content/` root only, but hive-project pages live under `docs/content/hive/`, so `existsSync` always failed for them and they never reached the search index (hivecommons/docs#155).
